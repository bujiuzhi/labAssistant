# UI/UX 设计规范

## 1. 适用范围

本规范适用于实验助手独立 Web 项目。原型源码和 QA 截图是业务页面内容、布局密度、可见文案与关键交互的实现基线；玄鉴宿主客户端的标题栏、左侧菜单和历史会话不属于本项目范围。

## 2. 设计原则

1. **实验上下文优先**：页面始终展示当前项目、实验编号、状态和负责人，避免记录归属不清。
2. **录入效率优先**：高频录入使用表格、批量粘贴、键盘导航和自动保存，减少弹窗层级。
3. **状态显式**：草稿、执行中、待检测、待审核、已完成等状态同时用文字和颜色表达。
4. **证据可追溯**：实验记录的修改、附件、提交和归档入口清晰可见。
5. **风险操作克制**：归档、作废、删除成员等操作需要说明影响，并在确认后执行。

## 3. 应用框架

系统采用实验助手独立项目布局：

- 产品栏：固定高度 `64px`，左侧展示“实验助手”品牌，中部展示一级业务导航，右侧展示当前用户与退出入口。
- 宿主能力：不显示玄鉴品牌栏、交通灯、问题反馈、在线状态、左侧菜单和历史会话。
- 业务导航：只显示“项目总览、项目数据、电子实验记录本”，不显示通用后台菜单和路由标签页。
- 主内容区：填满剩余高度，页面主体不产生浏览器级纵向滚动；超出内容仅在主卡片或表格内滚动。
- 内容边距：常规页面水平方向 `24px`；`1180px` 以下缩减为 `18px`。

项目、实验等二级能力由业务页面内部导航承载。普通研究人员只能访问有权限的数据和操作；前端隐藏不是权限控制依据。

## 4. 视觉令牌

设计令牌由前端统一维护，业务组件不得直接写入零散颜色值。

| 类别 | 令牌 | 建议值 | 用途 |
|---|---|---|---|
| 品牌色 | `--color-primary` | `#3157C8` | 主操作、选中状态 |
| 品牌悬停 | `--color-primary-hover` | `#2748AA` | 悬停 |
| 页面背景 | `--color-bg-page` | `#F5F7FB` | 应用背景 |
| 卡片背景 | `--color-bg-card` | `#FFFFFF` | 卡片、表格 |
| 主文字 | `--color-text-primary` | `#172033` | 标题、正文 |
| 次文字 | `--color-text-secondary` | `#667085` | 辅助说明 |
| 边框 | `--color-border` | `#E4E7EC` | 分隔线、控件边框 |
| 成功 | `--color-success` | `#168A5B` | 已完成、可用 |
| 警告 | `--color-warning` | `#B76508` | 待处理、即将超时 |
| 危险 | `--color-danger` | `#C9362B` | 失败、作废、删除 |
| 信息 | `--color-info` | `#2563A8` | 运行中、提示 |

基础圆角为 `6px`，主要卡片为 `8px`；基础间距采用 `4px` 倍数体系。正文最小字号为 `14px`，表格辅助信息可使用 `12px`。阴影仅用于弹出层和浮动元素，不用阴影堆叠页面层级。

## 5. 页面模板

### 5.1 列表页面

列表页由页头、筛选区、批量操作区和数据表组成：

- 页头展示标题、简短说明和一个主要操作。
- 常用筛选直接展示，低频筛选放入“更多筛选”。
- 查询条件同步到 URL，刷新或分享页面后可恢复。
- 表格表头固定，首列业务编号和末列操作列可固定。
- 空状态应说明无数据原因，并提供下一步入口。
- 批量操作仅在选中记录后出现。

项目和实验默认按 `updated_at` 降序排列。分页默认每页 20 条，可切换 50 或 100 条。

### 5.2 详情页面

详情页顶部固定展示业务编号、名称、状态、负责人和主要操作；主体采用标签页：

- 项目：概览、成员、实验、检测、文件、动态。
- 实验：计划、执行记录、材料、检测、附件、修订历史。

跨标签共享的数据只请求一次；切换标签不丢失未提交的草稿。存在未保存内容时，离开页面必须提示。

### 5.3 表单页面

- 新建流程不超过三个步骤：基础信息、实验设计、确认提交。
- 字段标签置于控件上方，必填标识与错误提示紧邻字段。
- 实验参数支持从模板载入，也允许在权限范围内调整。
- 保存草稿不要求所有业务字段完整；提交时执行完整校验。
- 后端校验错误必须映射到字段或页面级错误区域，不只使用短暂消息提示。

### 5.4 电子实验记录页面

电子实验记录采用“上下文 + 步骤记录 + 证据”布局：

- 顶部：实验编号、状态、项目、记录人、最近保存时间。
- 左侧或主区：实验步骤导航及完成状态。
- 中央：实际参数、现象记录、结论和异常。
- 右侧：材料批次、附件、修订记录；宽度不足时折叠为抽屉。
- 自动保存间隔为 30 秒，字段失焦后可触发增量保存。
- 离线或保存失败时显示持久提示，禁止伪造“已保存”状态。
- 提交后进入只读状态；退回时生成新修订，不覆盖已提交快照。

### 5.5 状态与反馈

| 场景 | 反馈方式 |
|---|---|
| 操作成功且无需后续动作 | 轻量消息，2–3 秒自动关闭 |
| 操作失败 | 页面或控件附近持久错误，并展示请求编号 |
| 长任务 | 任务状态条或通知中心，允许离开当前页面 |
| 危险操作 | 确认对话框，明确对象、影响和可恢复性 |
| 无权限 | 403 页面或局部禁用提示，不显示空白页 |
| 并发冲突 | 对比服务器版本与当前修改，允许重新加载或复制草稿 |

## 6. 响应式与浏览器支持

本项目只做网页，但核心生产场景按桌面端设计：

| 视口宽度 | 行为 |
|---|---|
| `>= 1440px` | 完整产品栏和双栏/三栏录入 |
| `1280–1439px` | 完整产品栏，辅助区可折叠 |
| `1024–1279px` | 产品栏保持单行，详情改为单主栏 |
| `< 1024px` | 支持查看和轻量审批，不保证复杂实验计划编辑体验 |

支持当前及前一个主要版本的 Chrome、Edge 和 Firefox。Safari 作为兼容性验证目标，不作为实验室受控终端的首选浏览器。

## 7. 可访问性

- 所有可交互元素支持键盘访问，并具有清晰焦点样式。
- 图标按钮必须提供可读名称。
- 颜色不作为唯一状态线索。
- 表单错误通过文本与控件关联。
- 正文和关键控件对比度满足 WCAG 2.2 AA。
- 动画尊重 `prefers-reduced-motion`，不使用无业务价值的循环动画。

## 8. 设计交付与验收

每个新页面至少交付以下状态：正常、加载、空、错误、无权限、只读。页面验收同时检查 1280px 和 1440px 视口，重点验证固定布局、内部滚动、长文本、100 条表格数据和未保存草稿提示。

设计变更涉及导航、状态含义、数据字段或权限时，必须同步更新对应正式规范，不能只修改设计稿。
