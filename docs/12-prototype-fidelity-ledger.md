# 原型复刻基线与保真台账

## 1. 基线与裁决规则

本项目不是重新设计。独立 Web 应用必须复刻原型的信息架构、可见文案、布局比例、视觉层级和关键交互，
只将原型中的静态数据与 `localStorage` 实现替换为 Vue、Django API 和持久化数据库。

原型基线目录：`/Users/bujiuzhi/Downloads/实验助手`。

证据优先级如下：

1. 页面当前 HTML、CSS、JavaScript 和 `shared/app-data.js` 决定功能、交互与数据口径。
2. 同页面修改时间最新的 `qa/*.png` 决定布局、密度、字号、颜色和组件外观。
3. `设计规范/` 和同目录其他页面用于补齐当前页面没有明确表达的细节。
4. 独立项目原有通用后台样式不构成设计依据。

## 2. 页面与路由映射

## 3. 全局外壳约束

- 视口基准为 `1660 × 900`，页面自身不产生横向滚动。
- 全局标题栏高 `48px`；左侧导航宽 `220px`；实验助手产品导航高 `48px`。
- 左侧导航和内容区均为浅色，禁止使用现有实现中的深色后台侧栏。
- 产品导航只显示“项目总览、项目数据、电子实验记录本”，禁止显示路由标签页。
- 顶栏品牌为“玄鉴”，包含交通灯、烧瓶图标、收起入口、问题反馈和在线状态。
- 左侧“实验助手”为蓝色选中态，底部展示登录用户；管理员基准文案为“刘李园 / 超级管理员”。
- 图标采用 Tabler/Remix 线性图标语义，不使用 Unicode 字符模拟图标。
- 页面内容背景、卡片、边框、文字、状态色以原型 `tokens.css` 为准。

## 4. 项目总览可见文案与组件

统计口径：

| 分组 | 指标 |
|---|---|
| 项目 | 项目总数、进行中、已归档、风险项目 |
| 实验 | 实验总数、进行中、已完成 |

图表和卡片：

- 图表标题只能使用“项目类型分布”“近30天实验趋势”。
- 分布图展示“按项目数”和“按实验数”，中心展示总数与单位，底部展示类型图例。
- 趋势图提供项目筛选，显示近 30 天日期范围、折线、坐标网格和图例。
- 项目区标题为“进行中项目”；卡片显示名称、日期、类型、负责人、目标和下一里程碑。
- 卡片延期、风险、正常三类状态必须通过边框、背景和倒计时徽标区分。

## 5. 首轮差异台账

| 对照点 | 原有独立实现 | 原型基线 | 处置 |
|---|---|---|---|
| 全局外壳 | 深色侧栏、56px 顶栏 | 48px 浅色玄鉴栏、220px 浅色侧栏 | 重构 |
| 一级导航 | 工作台/项目管理等六项 | 三项实验助手产品导航 | 重构 |
| 页面头部 | 欢迎语、日期、新建按钮 | 无欢迎语，指标直接开始 | 删除偏离内容 |
| 项目指标 | 四个通用 KPI | 项目四项 + 实验三项两组指标 | 重构 |
| 数据可视化 | 无 | 双分布环图 + 30 天趋势图 | 新增 |
| 项目呈现 | 最近项目表格 | 三列项目卡片及里程碑状态 | 重构 |
| 项目数据 | 通用查询表格和弹窗 | 状态页签、多维筛选、字段计数、右侧抽屉 | 重构 |

| 用户展示 | 通用头像菜单 | 侧栏底部姓名、角色、设置入口 | 重构并保留退出能力 |

## 6. 验收方法

每个页面完成后执行以下检查：

1. 在 `1660 × 900`、`1440 × 900` 两种桌面视口核对布局，不允许内容重叠或页面横向滚动。
2. 将实现截图与对应最新 QA 截图按外壳、导航、首屏层级、文案、控件密度至少五项逐项对照。
3. 执行可见文案差异检查；非登录、异常提示和权限说明不得出现原型外文案。
4. 执行键盘焦点、按钮点击、筛选、抽屉和路由跳转检查。
5. 记录浏览器控制受限等未完成项；没有实际完成浏览器验收前不得标记“视觉验收通过”。
