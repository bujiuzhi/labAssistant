# 项目规范索引

## 使用原则

- `docs/` 是正式项目规范的唯一存放位置。
- `audit/` 只保存来源、证据和派生审计，不替代正式规范。
- `contracts/openapi.yaml` 是设计优先的接口协议草案；实现阶段由 CI 校验服务端响应与契约一致性，并据此生成前端类型。
- 数据库进入实现阶段后，以 Django migrations 为结构唯一来源；数据字典负责业务语义和字段约束。
- 文档状态分为“草案、评审中、已批准、已废止”。未批准内容不得作为上线验收依据。

## 当前需要确认

1. 四类角色的最终职责，以及外部检测结果是否允许由研究人员代录。
2. 实验归档后是否允许修订，以及修订是否需要项目负责人复核。
3. 浏览器关闭后的提醒渠道采用邮件、企业微信还是 Web Push。
4. 首期是否必须包含工艺积木拖拽；若必须，需同时提供键盘排序方案。
5. 单组织部署还是从首期支持多个组织。
