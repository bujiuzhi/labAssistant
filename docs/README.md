# 材料实验助手项目规范

`docs/` 仅保留三份正式规范。当前运行事实以已提交源码、Django Migration、自动化测试和部署配置为准；`audit/` 保存原型证据和历史审计，`contracts/openapi.yaml` 为接口草案。

| 文档 | 适用内容 | 使用者 |
|---|---|---|
| [概要设计](overview-design.md) | 业务范围、角色边界、架构、关键流程、非功能要求和验收口径 | 产品、业务、技术负责人 |
| [详细设计](detailed-design.md) | 实现结构、数据表字段、API、并发与错误约定、权限、页面、文件预览和测试映射 | 前后端开发、测试、技术评审 |
| [开发部署与运维指南](development-operations-guide.md) | 环境、启动检查、测试、发布、备份、回滚、安全、Git 和文档维护 | 开发、测试、运维 |

推荐阅读路径：业务或管理评审先阅读《概要设计》中的范围、用例、架构与验收口径；研发评审继续阅读《详细设计》中的类图、ER 图、状态机、接口与权限；发布前按《开发部署与运维指南》的环境、检查、备份和回滚清单执行。

## 维护规则

- 变更范围、架构或已实现边界时更新《概要设计》。
- 变更表、接口、权限、页面或测试时更新《详细设计》。
- 变更环境、部署、测试、发布或协作方式时更新《开发部署与运维指南》。
- 新增功能必须先完成 Migration、接口、权限与自动化测试，再同步三份规范。
