# 实验助手 · 玄鉴桌面端设计规范 v1.2

## 1. 视觉原则

- 实验助手位于玄鉴客户端全局头部下方，不改变客户端品牌头部结构。
- 页面分区优先使用背景明度、留白和选中态，不使用连续描边堆叠层级。
- 玄鉴品牌色维持冷灰底色、白色工作面与钴蓝强调色；状态色只表达语义。

## 2. 表面层级

| 层级 | Token | 用途 |
| --- | --- | --- |
| 客户端工作底 | `--color-shell` | 页面内容区、卡片之间的间隔 |
| 主工作面 | `--color-paper` | 侧栏、导航、表格、表单与记录卡片 |
| 次级工作面 | `--color-paper-2` | 表头、分组标题、筛选标签区 |
| 选中/强调面 | `--color-accent-soft` | 当前导航、当前项目、选中记录 |

主要工作面允许使用 `--shadow-surface` 的轻微阴影建立悬浮层级；同色相邻区域不得同时叠加外框和阴影。

## 3. 线条使用规则

- 白色与灰色表面之间不画边界线，依靠明度差识别区域。
- 客户端头部、左侧菜单、实验助手二级导航不使用贯穿式分隔线。
- 卡片、筛选区和表格容器不使用外框；卡片之间以 8–12px 间距分组。
- 表格仅保留低对比度横向行分隔，禁止纵向网格线。
- 输入框、选择器、可拖拽区、弹窗和键盘焦点保留功能性边界。
- 当前标签使用 2px 钴蓝下划线；当前菜单使用浅蓝底色，不额外描边。

## 4. 字体与字号层级

### 4.1 字体

- UI 正文：`Source Han Sans SC, PingFang SC, system-ui, sans-serif`。
- 品牌与数字强调：`Avenir Next, PingFang SC, sans-serif`。
- 数据与代码：`SFMono-Regular, Consolas, Liberation Mono, monospace`。

### 4.2 字号

| 场景 | 字号 | 字重 | 行高 |
| --- | --- | --- | --- |
| 页面标题 | 22px | 600 | 1.3 |
| 工作区/详情标题 | 18–20px | 600 | 1.3 |
| 弹窗标题 | 20px | 600 | 1.3 |
| 卡片/分栏标题 | 14px | 500–600 | 1.4 |
| 表单输入/表格正文 | 14px | 400–500 | 1.5 |
| 表格表头 | 13px | 500–600 | 1.4 |
| 字段标签/筛选条件 | 13px | 500 | 1.4 |
| 按钮/模块导航 | 13–14px | 500–650 | 1.2 |
| 辅助信息/状态标签 | 12px | 400–500 | 1.4 |

- 常规业务正文不得低于 14px；仅辅助说明、状态标签和时间戳允许使用 12px。
- 输入框内容必须为 14px，Label 为 13px；不得通过缩小字号解决表单拥挤，应优先调整宽度、换行或间距。
- 表格仅表头使用 13px，数据单元格统一使用 14px，以保证高密度数据的扫描效率。
- 页面标题与正文至少相差 8px，卡片标题与正文通过字重而非继续放大字号建立层级。

### 4.3 字号 Token

| Token | 数值 | 用途 |
| --- | --- | --- |
| `--text-xs` | 12px | 辅助信息、状态标签 |
| `--text-sm` | 13px | Label、表头、筛选条件 |
| `--text-base` | 14px | 正文、表单、表格单元格 |
| `--text-md` | 16px | 品牌、强调文字 |
| `--text-lg` | 18px | 工作区标题 |
| `--text-xl` | 22px | 页面标题 |
| `--text-2xl` | 24px | 特殊一级标题，谨慎使用 |

## 5. 左侧菜单折叠

- 默认宽度 220px；中等窗口宽度为 142px。
- 点击头部侧栏按钮后，菜单宽度收敛至 0，主工作区同步扩展。
- 折叠状态在项目总览、项目数据、电子实验记录本和项目详情路由之间保持一致。
- 折叠后按钮图标切换为“展开侧栏”，并同步更新 `aria-label` 与 `aria-pressed`。
- 小于 560px 时侧栏保持隐藏，头部不显示折叠按钮。

## 6. 可访问性与动效

- 控件的焦点样式必须可见，不用移除边框的方式牺牲键盘可用性。
- 折叠动效时长 180ms；系统开启“减少动态效果”时关闭过渡。
- 文本、状态色与背景需满足桌面工作台的可读性要求；语义不得只依赖颜色表达。
- 页面缩放至 125% 时，主要导航、表单操作和表格数据不得出现遮挡或不可访问状态。

## 7. 表单控件

### 7.1 统一视觉

- 文本输入框、日期/时间输入框、数字输入框、选择器与多行文本框统一使用浅蓝色工作面 `--color-input-bg`，不得在同一业务表单内混用纯白、灰色和浅蓝背景。
- 默认边框使用低对比度灰蓝色 `--color-input-border`；悬停时适度提高蓝色对比度，不改变控件尺寸。
- 占位文字使用浅灰蓝色 `--color-input-placeholder`，必须明显弱于已填写内容，同时满足可读性要求。
- 聚焦态只显示一层钴蓝边框与一层 3px 浅蓝外光晕；禁止同时叠加浏览器 outline、内边框和外层容器焦点框形成双蓝框。
- 禁用与只读状态必须保留文字可读性，并通过降低背景/文字对比度表达，不依赖缩小字号。

### 7.2 尺寸与对齐

- 标准表单中的单行输入框、日期/时间控件和选择器统一为 40px 高、6px 圆角、左右 12px 内边距。
- 紧凑筛选区和高密度表格编辑器允许使用 32–34px 高，但颜色、圆角、占位文字和焦点规则必须与标准控件一致。
- 同一行中的输入框、日期/时间控件和状态选择器必须底部对齐；不得因原生日期图标或选择器箭头造成基线、高度或下边框错位。
- 选择器箭头与日期图标位于控件右侧固定区域，不得压住文字；最长选项必须能在控件内正常显示或省略。
- Label 使用 13px，控件内容使用 14px；控件间距不足时优先扩展布局或换行，不得缩小字号。

### 7.3 适用范围

- 本标准适用于新建/编辑项目、项目里程碑、实验计划、电子实验记录本及后续新增业务表单。
- 搜索框由外层容器承载边框时，内部输入框保持透明且无独立焦点框，整体仍遵循浅蓝背景和单层焦点反馈。
- 复选框、单选框、文件上传按钮、无边框表格标题编辑器等特殊控件不直接套用单行输入框尺寸，但其焦点反馈必须保持一致。
