# 前端按钮设计系统变更记录

- 变更时间：2026-08-04 11:34:55
- 变更范围：实验助手前端按钮视觉与交互状态统一
- 数据影响：无数据库、接口或业务数据变更

## 变更资产

- 新增 `frontend/src/styles/buttons.css`，作为主按钮、次按钮、轻量按钮和危险按钮的唯一公共样式来源。
- 新增 `frontend/tests/button-design-system.test.ts`，校验基础尺寸、四类语义、交互状态及危险/禁用配色。
- 调整首页、项目列表、项目详情、文档资料、电子实验记录本、用户管理和账户入口中的动作按钮语义。
- Element Plus 弹窗和消息框按钮纳入同一设计系统；项目归档确认按钮显式使用危险语义。

## 规范落实

- 统一高度 36px、横向内边距 16px、圆角 6px、字号 14px、字重 500、图标 17px、图文间距 6px。
- hover、active、focus-visible、disabled 均由公共样式定义，active 统一缩放至 0.97。
- 编辑、取消、筛选和复制使用次按钮；模块新增与上传入口使用轻量按钮；创建、保存和确认使用主按钮；归档、删除和移除使用危险按钮。
- 描边按钮不再保留独立视觉层级，统一按次按钮呈现。

## 验证记录

- 远程环境前端自动化测试：10 项全部通过。
- 远程环境 `vue-tsc -b && vite build`：通过；仅保留既有大分包体积提示。
- 本地与远程本次变更文件 SHA-256：逐项一致。
- 远程页面：首页结构与真实数据加载正常；后续浏览器自动化因安全校验服务暂时不可用而停止，未绕过安全校验。

## 布局回归修复

- 用户管理操作列增加固定单行容器并清除 Element Plus 默认相邻按钮外边距，避免“编辑”和“重置密码”在表格行内错位换行。
- 操作列宽度由 220px 调整为 240px，为两个标准 36px 次按钮保留稳定空间。
- 增加用户管理操作按钮单行排列的静态回归断言。
