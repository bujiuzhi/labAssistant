# 项目详情路由参数修复记录

## 1. 问题现象

从“项目总览”点击项目卡片后进入详情路由，但页面提示“项目详情加载失败”。

## 2. 根因

总览卡片使用原型业务编号作为路由参数，例如 `PRJ-2026-PI-005`；原详情页无条件将该参数作为数据库 UUID 请求
`GET /api/v1/projects/{projectId}`，导致后端无法匹配项目。

## 3. 修复

| 资产 | 动作 | 说明 |
|---|---|---|
| `frontend/src/views/projects/ProjectDetailView.vue` | 修复 | 原型编号读取保真数据，数据库 UUID 继续读取真实 API |
| `frontend/src/data/prototype-dashboard.ts` | 同步依赖 | 提供总览与详情共享的稳定项目数据 |

详情加载失败时不再显示错误项目作为兜底，而是显示明确空状态并提供返回入口。

## 4. 回归范围

- 从项目总览卡片进入原型项目详情。
- 从项目数据列表进入数据库项目详情。
- 详情加载失败时的错误提示和返回入口。
- Vue 类型检查及生产构建。

## 5. 验证结果

- 远程执行 `pnpm --dir frontend run build`，Vue 类型检查与 Vite 生产构建通过。
- 原型业务编号分支命中 `prototypeProjects`，不再请求 UUID 详情接口。
- 数据库 UUID 分支继续调用 `projectApi.get`，保留真实项目详情能力。
- 浏览器插件仍拒绝访问本地转发地址，本次未声明浏览器交互与截图验收通过。
