# 邀请注册与自助改密变更记录

时间：2026-09-09 17:30:00（Asia/Shanghai）

## 决策与影响

- 首版生产库尚未部署，注册邀请码结构并入 V1 初始物理结构；已部署环境后续变更只能新增版本迁移。
- 仅超级管理员可签发、查看和撤销邀请码。邀请码使用 192 位随机值，数据库只保存 SHA-256 哈希，明文仅在签发响应中返回一次。
- 每个邀请码绑定当前组织、普通角色及 1 至 720 小时有效期，只可由一个注册事务原子消费；不能签发超级管理员邀请码。
- 注册接口不自动登录，不允许提交组织或角色；用户登录后可校验旧密码修改自身密码，成功后当前 Servlet Session 立即失效。

## 验证与恢复

- 已补充服务端邀请码哈希、原子消费和改密校验单测，以及前端静态回归测试；目标 Java 25 运行验证须使用项目指定 JDK。
- 本变更不创建公开无邀请码注册入口，不写入邀请码明文、密码或生产身份数据。
- 首版尚未部署时，如需放弃此功能，恢复至本变更前的已审查 V1 源码；生产部署后不得改写已执行 V1，应新增兼容迁移和前向恢复方案。
