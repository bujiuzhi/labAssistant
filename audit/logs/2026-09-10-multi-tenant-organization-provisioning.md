# 2026-09-10 多租户组织开通

- 时间：2026-09-10  Asia/Shanghai
- 决策：采用“单账号单组织 + 平台管理员开通组织”的首版多租户模型。首次 `bootstrap` 管理员同时标记为平台管理员；后续组织由其在受控界面/API 中创建。新组织在同一事务内获得首个组织超级管理员、三个内置角色和角色权限。
- 数据与安全影响：新增 V1 基线字段 `user_account.is_platform_admin`。平台管理员只能读取组织目录、开通组织，不获得其他组织的项目、实验、文档、附件、邀请码或普通用户管理访问权；业务查询继续以当前会话 `organization_id` 为边界。新组织管理员不继承平台标记，邀请码仍只能创建所属组织的非超级管理员。
- 发布边界：当前尚未进行首版生产初始化，因此字段纳入 V1 空库基线；不得将修订后的 V1 用于已执行 V1 的共享或生产数据库。若已有本地开发库，应在确认其仅含可丢弃开发数据后重建，而非手工改写 Flyway 历史。
- 恢复要点：在首版发布前可通过回退本次源码及以空库重建恢复。首版发布后若需改变字段或组织模型，只能新增 Flyway 版本迁移并准备备份、验证与补偿方案。
- 验证：2026-09-10 使用 `maven:3.9.12-eclipse-temurin-25` 容器执行 `mvn test`，61 项通过；`pnpm --dir frontend test` 20 项通过，`pnpm --dir frontend run build` 通过；Ruby YAML 解析 OpenAPI 通过，`git diff --check` 通过。宿主 JDK 不支持项目的 release 25，未将其失败计作代码失败。
