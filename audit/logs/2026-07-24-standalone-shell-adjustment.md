# 实验助手独立外壳调整记录

## 1. 触发原因

用户确认本项目是只针对实验助手的独立 Web 项目，不应继续展示玄鉴宿主客户端的顶部栏、左侧菜单和历史会话。

## 2. 变更资产

| 资产 | 动作 | 说明 |
|---|---|---|
| `frontend/src/layouts/AppShell.vue` | 重构 | 删除玄鉴外壳，改为实验助手独立产品栏 |
| `frontend/src/router/index.ts` | 更新 | 浏览器标题去除玄鉴后缀 |
| `docs/00-document-control.md` | 更新 | 新增 ADR-006，明确独立项目边界 |
| `docs/02-system-architecture.md` | 更新 | 删除侧栏折叠偏好描述 |
| `docs/03-ui-ux-design-specification.md` | 更新 | 将全局布局修订为独立产品栏 |
| `docs/12-prototype-fidelity-ledger.md` | 更新 | 将宿主外壳从原型复刻范围排除 |

## 3. 保留能力

- 保留“项目总览、项目数据、电子实验记录本”三项业务导航。
- 保留当前用户姓名、角色和退出登录能力。
- 项目详情、实验管理等二级页面继续使用页面内部导航。
- 原型仍作为实验助手业务内容、视觉密度和关键交互的实现基线。

## 4. 清理边界

需要撤回本次调整时，仅回退本记录列出的资产。不得删除项目、实验、ELN 数据或回退与本次外壳无关的数据库迁移。
